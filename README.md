# Словарь ударений для ИИ-озвучки

Слова, в которых ElevenLabs и другие ИИ-модели ставят ударение не туда. Собран на живой озвучке 3D-игры «Вершина» и шортов канала Лламочка.

Страница со списком: https://llamochka.github.io/udareniya/

## Как пользоваться

Только словарь, без лишних библиотек:

```
echo "Сегодня катка не задалась" | python3 scripts/udarenie.py
# Сегодня ка́тка не задалась
```

Модель RuAccent расставляет ударения во всём тексте, словарь правит её ошибки:

```
pip install -r requirements.txt
echo "Мы сидим дома, а дома стоят у реки" | python3 scripts/udarenie.py --ruaccent
# Мы сиди́м до́ма, а дома́ стоя́т у реки́
```

Для агента: перед озвучкой прогоняй текст через `scripts/udarenie.py` или подставляй слова из `slovar.json` сам. Знак ударения U+0301 стоит после ударной гласной. Слова с пометкой «омограф» автозаменой не ставятся: ударение зависит от смысла.

## Как пополняется

Слова добавляет автор, когда слышит ошибку в своей озвучке. Каждое сверяется с Викисловарём (`scripts/wiki.py`).
